# nymo

nymo schwärzt Namen und persönliche Angaben in Akten, bevor Claude sie liest. Es läuft nur auf dem eigenen Rechner, nichts geht ins Internet.

**Download für Windows 10 und 11:** [nymo-windows.zip](https://github.com/lifetimeai/nymo/releases/latest/download/nymo-windows.zip) (rund 1,2 GB)

Das Zip bringt alles mit: Python, Poppler, die Texterkennung für Scans (RapidOCR) und die KI-Erkennung mit dem Sprachmodell. Nichts ist zu installieren, keine Administrator-Rechte nötig.

1. Zip entpacken (rechte Maustaste → „Alle extrahieren“) in einen kurzen Ordner, etwa `C:\Users\<name>\nymo`, nicht in OneDrive.
2. Im Ordner `nymo` doppelt auf „nymo starten“ klicken. Windows warnt eventuell beim ersten Start: „Weitere Informationen“ → „Trotzdem ausführen“. nymo legt die Verknüpfung „nymo“ auf den Schreibtisch und ins Startmenü.

Anleitung und Hintergrund: die `README.md` im Ordner `nymo` des Zips. Mehr unter [aibene.de](https://aibene.de).

Dieses Repository enthält nur die Releases.
